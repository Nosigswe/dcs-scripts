## Getting started

You need [Git](https://git-scm.com/downloads) and a [GitHub](https://github.com) account.

### 1. Clone the repository

Cloning downloads a copy of the repository to your computer:

```sh
git clone https://github.com/Nosigswe/dcs-scripts.git
cd dcs-scripts
```

### 2. Create a branch

Don't work directly on `main`. Create a branch for your change and give it a short, descriptive name:

```sh
git checkout -b my-change
```

### 3. Make and commit your changes

Edit the files, then save your work in a commit:

```sh
git add .
git commit -m "Describe what you changed"
```

### 4. Push your branch to GitHub

```sh
git push -u origin my-change
```

If you don't have write access to this repository, [fork it](https://docs.github.com/en/get-started/quickstart/fork-a-repo) on GitHub first, clone your fork, and push to that instead.

### 5. Open a pull request

1. Go to https://github.com/Nosigswe/dcs-scripts.
2. GitHub shows a **Compare & pull request** button for your recently pushed branch. Click it.
3. Write a title and a short description of what you changed and why.
4. Click **Create pull request**.

Someone will review your pull request. If changes are requested, make them on the same branch, commit, and push again. The pull request updates automatically.
